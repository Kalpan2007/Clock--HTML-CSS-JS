# Digital Clock

A modern digital clock with an animated circular progress indicator, built using HTML, CSS, and JavaScript.

## Features
- Displays current time in hours, minutes, and seconds.
- Uses a 12-hour format with AM/PM indicator.
- Circular stroke animations for each time unit.
- Smooth dot movement for time progression.
- Fully responsive and stylish UI.

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/your-repo.git
   ```
2. Navigate to the project directory:
   ```sh
   cd your-repo
   ```
3. Open `clock.html` in a browser.

## File Structure
```
/
│── clock.html    # Main HTML file
│── clock.css     # Styling for the clock
│── clock.js      # JavaScript for clock functionality
└── README.md     # Project documentation
```

## Usage
- Open `index.html` in your browser to view the clock.
- The clock updates every second with smooth animations.
